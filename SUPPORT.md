# 获取支持

感谢使用 pi-gui-zh。请按下表选择正确的渠道，这样问题能被更快地处理。

| 需求                         | 渠道                                                                                                             |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 使用问题、经验交流、想法讨论 | [GitHub Discussions](https://github.com/ilovemajiaqi/pi-gui-cn/discussions)                                      |
| 可复现的缺陷                 | [提交 Bug 报告](https://github.com/ilovemajiaqi/pi-gui-cn/issues/new?template=bug_report.yml)                    |
| 功能建议                     | [提交功能请求](https://github.com/ilovemajiaqi/pi-gui-cn/issues/new?template=feature_request.yml)                |
| 安全漏洞                     | [私密报告](https://github.com/ilovemajiaqi/pi-gui-cn/security/advisories/new)，详见 [SECURITY.md](./SECURITY.md) |
| 参与开发                     | [CONTRIBUTING.md](./CONTRIBUTING.md)                                                                             |
| 社区行为问题                 | [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md)                                                                       |

## 提交问题前

1. 搜索现有 Issue 与 Discussions，避免重复；
2. 确认使用的是[最新版本](https://github.com/ilovemajiaqi/pi-gui-cn/releases)或 `main` 分支；
3. 阅读 [README](./README.md) 与 [docs/](./docs) 中的说明；
4. 从日志和截图中移除 API Key、Token、会话内容等敏感信息。

## 上游与中文版的分工

- 与**中文本地化、语言切换、中文字体/排版**相关的问题，请提交到本仓库；
- 与 **pi 运行时、provider、上游原有功能**相关的问题，请优先提交到[上游仓库](https://github.com/minghinmatthewlam/pi-gui/issues)，并注明是否只在中文版出现；
- 本仓库是社区维护的非官方中文版，与上游项目没有隶属关系。

## 响应预期

这是一个由社区维护的项目，维护者会在力所能及的范围内回复。请保持耐心，并尽量提供完整、可复现的信息。中文或英文均可。
